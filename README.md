# lanchote-byte
Este repositório tem como objetivo praticar python por meio de uma atividade proposta pelo meu professor
onde temos que criar um sistema de caixa dentro do terminal para uma lanchonete.

Etapa 1 — Abrindo o caixa (10 pts)
O caixa precisa se apresentar e registrar quem está atendendo e quem é o cliente.

Etapa 2 — A conta (15 pts)
O cliente pediu hambúrgueres e refrigerantes. O caixa precisa calcular a conta e o troco.

Etapa 3 — Promoções
O dono quer dar desconto conforme o valor da compra e liberar brinde pra quem paga em
dinheiro.

Etapa 4 — O cardápio
O cardápio agora fica guardado em listas. Ainda sem for nesta etapa: só índices e métodos.

Etapa 5 — Fila de pedidos
No fim do dia, o caixa precisa listar o cardápio e fechar as vendas.

Etapa 6
Juntem tudo num único arquivo caixa_byte.py. O sistema atende um cliente do começo
ao fim.
